# Kamatchinathan Sankarapandian — Portfolio

A responsive single-page portfolio website designed from the information in the CV.

## Files

- `index.html` — portfolio structure and content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation
- `assets/` — place your PDF CV here

## GitHub Pages deployment

1. Create a new GitHub repository, for example:
   `kamatchinathan-portfolio`
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. Put your CV PDF inside:
   `assets/Kamatchinathan_Sankarapandian_Project_Engineer_UAE.pdf`
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save. GitHub will publish your portfolio.
